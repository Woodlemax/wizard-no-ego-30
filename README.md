# Wizard без раздутого ЭГО

Одностраничный счётчик с берндауном на 30 дней. GitHub Pages, без сервера и внешней базы данных.

Дата начала, причина и ссылка находятся в `counter.json`. Страница вычисляет дни по часам устройства посетителя и перечитывает файл каждые 30 секунд. После 30 дней число прошедших дней продолжает расти, остаток остаётся нулём.

## Сброс через API

На своём компьютере с Node.js и GitHub CLI выполните:

```sh
gh auth login
node reset-counter.mjs "Причина сброса" "https://example.com/incident"
```

Для определённой даты добавьте третий аргумент:

```sh
node reset-counter.mjs "Причина" "https://example.com/incident" "2026-09-10T23:00:00+04:00"
```

Без аргументов скрипт начинает отсчёт заново с текущего момента, очищая причину и ссылку. Скрипт использует сохранённый вход GitHub CLI или переменную окружения GH_TOKEN / GITHUB_TOKEN. Для отдельного fine-grained токена нужен доступ только к этому репозиторию и разрешение Contents: write. Не сохраняйте токен в репозитории или коде страницы.

API: GET /repos/Woodlemax/wizard-no-ego-30/contents/counter.json для получения sha; затем PUT на тот же адрес с branch: main, sha, message и content (JSON в Base64). Это GitHub API, прежний POST /api/reset здесь не используется.

Сброс с локальным скриптом вызывает публикацию Pages. Изменения могут появляться до 10 минут. Если автоматизировать сброс внутри GitHub Actions, встроенный GITHUB_TOKEN сам по себе не запускает обычную публикацию Pages от ветки: нужен отдельный процесс deployment либо подходящий пользовательский токен.

Дата, причина, ссылка и их история изменений публичны. Начало отсчёта при переносе: 10 сентября 2026, 23:00, Самара (UTC+4).
